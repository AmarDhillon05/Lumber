# Lumber — native iOS app (Swift / SwiftUI)

A native rewrite of the React Native app in the repo root. It ships alongside
it as **"Lumber (native)"** (`com.amardhillon.lumber.native`) in the SideStore
source until it reaches parity, then replaces it.

## Layout

- `LumberCore/` — Swift package with all platform-independent logic. Builds and
  tests on **Linux** (`swift test`), so it is verified without a Mac.
  Behaviour matches the TypeScript originals in `../src` via golden fixtures
  generated by `../scripts/native/` and checked in under `Tests/LumberCoreTests/Fixtures`.
- `App/` — the SwiftUI app: `AVAudioEngine` (song playback + mic on one clock),
  `AVCaptureSession` (camera), `AVAssetExportSession` (video/M4A), ONNX Runtime
  (Swift package, Core ML EP) for drum removal, Keychain, Photos,
  `ASWebAuthenticationSession` (Spotify). Depends on `LumberCore`.
- `project.yml` — XcodeGen spec; the `.xcodeproj` is generated on CI, never committed.

## Conventions

- Swift 6, strict concurrency. iOS 17+.
- No third-party dependencies except ONNX Runtime.
- Port behaviour, not structure: keep the TS algorithms and constants exact
  (presets, ranges, DSP math, Demucs constants) and prove it with fixtures.
- Colors come from `Theme.swift` (purple/gray/blue palette from `../src/theme.ts`).

## Build

- Linux: `cd native/LumberCore && swift test`
- iOS: `.github/workflows/native-ios.yml` (XcodeGen → unsigned `xcodebuild` → `.ipa`
  → release + SideStore source entry).
